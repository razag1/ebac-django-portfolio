
# Django Portfolio - EBAC

Projeto desenvolvido durante o curso Full Stack Python
da EBAC, como parte do módulo de configuração do Django.

## Tecnologias

- Python
- Django
- SQLite
- Git e GitHub

## Objetivo

Criar e configurar um projeto Django com uma aplicação
chamada blog, executar o servidor e validar o
funcionamento da página inicial.

## Execução

1. Instalar as dependências:
   pip install -r requirements.txt

2. Executar as migrações:
   python manage.py migrate

3. Iniciar o servidor:
   python manage.py runserver
